Vraki Language The writing behind #HusbandOutWorld, on Windows since 2017

In 2017, Vraki was a small Windows app that reversed, shifted and restructured English until it read like a new language. That idea grew into the script of the #HusbandOutWorld series and its own typeface. The original app is back, as it was, for the record.

This is old code, on purpose. Vraki Language was written in 2017 as a Universal Windows Platform app for Windows 10 and published on the Microsoft Store. Its source is resurrected here for historical purposes: the C# and XAML are unchanged, only moved into legacy/.

Since then, Vraki has become the writing system of the #HusbandOutWorld series, written 1:1 with English: one Vraki glyph per English letter, instead of the 2017 app's reversing and shifting. A modern version built around that idea is the next step for this repository.

Where Vraki came from

Deovandski always dreamed of coming up with a language. As a child he doodled the alphabets of alien civilizations, and the more he traveled the world and soaked up its cultures, the closer those doodles drifted to the Vraki writing you see here.

From doodles to a world

He didn't expect it to grow into an entire world with extensive lore, and from there into several stories. This app is where the writing first went digital, back in 2017.

The Vraki typeface

The 2017 README ended with a hand-drawn sketch and a promise: "If time allows, I will develop a cleaner version of the following drawing followed by a font." That font now exists, made for the #HusbandOutWorld series, and it lives in the HusbandOutWorld repository.

One glyph per English letter

  • Vraki is English with a different skin: same alphabet, same order, same words. Type in English and it's written in Vraki.
  • Each letter is a line drawn across a dotted grid. Upper case letters carry small circle markers; lower case is the same stroke without them.
  • Digits mark a single dot on a 3×3 grid (zero marks all nine), and punctuation has its own marks.
  • In the series' lore, Vraki is the common language inherited from the Finaies: mostly English, because English is the common language for business and the language the books were written in.

How the 2017 conversions work

Four building blocks, run in order: Reverse, Shift, Vraki Structure, then Letter Case Fix. Each conversion type is a preset of them. Here's what each does to the app's sample sentence, "Look at my Horse! My horse is amazing! -Gentleman":

Conversion typeStepsOutput
DefaultChar reverse, shift all by −3, letter caseKxjbiqkbd- !Dkfwxjx pf bpole vj !Bpole vj qx hlli
Simple VrakiVraki structure, letter caseLook at my hol-li`lde! My hol-li`lde is amazing! -Gentleman
Complex VrakiChar + word pair reverse, consonants −10, vowels +2, Vraki structure, letter caseTbi-rg`ldbzhoy- !Itzbiun ug voagf zm !Voagf zm ih yxaa
MinimalShift all by +1, letter caseMppl bu nz ipstf! Nz ipstf jt bnbajoh! -Hfoumfnbo

The full write-up, with the 2017 diagrams for every reverse algorithm and the Vraki structure table, is in docs/ALGORITHMS.md.

Privacy

The app stores nothing about you; the text you convert stays on your device. This website has no cookies, no analytics and no ads, and the converter and typeface preview run entirely in your browser. It's hosted on GitHub Pages, so GitHub sees your IP address when it sends you the page. Questions go to GitHub issues.
