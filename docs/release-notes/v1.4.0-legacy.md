**Vraki Language, the 2017 app, resurrected for historical purposes.**

This is the source of the Universal Windows Platform app published on the Microsoft Store in 2017, at its last version, 1.4, moved into a new repository layout. The C# and XAML are unchanged.

### Install

The app is on the **[Microsoft Store](https://apps.microsoft.com/detail/9P41XHS4HMLX)**.

### Downloads

- `VrakiLanguage-1.4.0-legacy-source.zip`: the 2017 source, docs and design files.
- `VrakiLanguage-1.1.0.0-2017-sideload.zip`: the only built package that survived, version 1.1.0.0 from 29 May 2017, with Visual Studio's install script. **Historical only:** its self-signed certificate expired on 30 May 2018, so current Windows is expected to refuse it. Use the Store instead.

### Version history (2017)

- **1.4**: Fixed issues #2 and #3.
- **1.3**: Changed the header image to support VisualStates, and updated the GitHub links.
- **1.2**: Changed how the current panel and the writable panel are shown.
- **1.1**: The version in the sideload package above.

### What's in the repository

- `legacy/`: the 2017 Visual Studio solution, with its manifest identity replaced by a development one (the Store identity is kept out of git; see `docs/STORE.md`).
- `docs/ALGORITHMS.md`: how the conversions work, with the original diagrams.
- `docs/2017-design/`: the original design files.
- A website at https://deovandski.github.io/vraki-windows/ that runs the 2017 converter in the browser (a JavaScript port checked against the app's own output) and shows English in the [Vraki typeface](https://github.com/Deovandski/HusbandOutWorld/tree/main/Logo%20and%20Font).
